Magictory

Magictory

A medieval automation and arcane magic game.

Nombre: Magictory

Desarrollador: FranForge

Periodo: Aug 2025 - Nov 2025

Tecnologías: Unity, C#, Github

Sinopsis: In a world consumed by dark beings, the king sends you, a simple trusted mage capable of shaping magic to make things work. This is where your adventure begins, building a settlement capable of housing magical protections so the people can live freely.

Género y Etiquetas: Automation, resource management, crafting, base building, construction.

Sistemas en los que trabajé

Inventory and items

  • ScriptableObjects to define resource types and reduce memory usage
  • Structs to represent resource stacks
  • Structs instead of classes and arrays instead of lists to reduce GC
  • Crafting system based on resource recipes

Descripción

Full system based on ScriptableObjects defining each resource type. A stack struct holds the resource reference and quantity. The inventory stores an array of stacks with a maximum capacity defined in Unity.

Interaction system

  • Interface-based interaction system
  • Detection using Physics.OverlapSphere

Descripción

Interaction system based on interfaces implemented by every interactable object. Each object handles its own logic while player movement is blocked during interaction for consistency.

Construction system

  • Dedicated ActionMap for precise building control
  • ScriptableObjects defining structures
  • Progressive unlocking of structures
  • Dependencies and connections between structures
  • Interface-based requirement validation

Descripción

Construction system using a dedicated ActionMap allowing free camera and cursor control. Structures are defined via ScriptableObjects and unlocked progressively. Before placement, each structure validates material and space requirements.

Custom tick system

  • Resource optimization via centralized calls
  • Periodic ticks using IEnumerators and Coroutines
  • Interface-based implementation (ITickable)
  • Strict separation between logic and visuals

Descripción

TickManager executing logic periodically for all ITickable objects using coroutines, reducing reliance on Update for frequent calculations.

World chunking system

  • Performance optimization via world segmentation
  • Loading/unloading zones based on player distance

Descripción

World divided into chunks that load or unload based on player distance, reducing resource usage by disabling irrelevant areas.

Level of detail (LOD)

  • Multiple levels of detail for performance optimization

Descripción

Implemented multiple LOD levels to maintain stable performance in complex environments.

Character movement (NavMesh)

  • Pathfinding using Unity NavMesh
  • NavMeshObstacles for dynamic elements
  • Point & click movement system
  • Separated mouse and controller input

Descripción

Top-down movement system using NavMesh pathfinding with cursor. Also includes controller movement support for different platforms.
