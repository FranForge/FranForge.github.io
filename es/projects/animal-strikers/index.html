Animal Strikers

Animal Strikers

A casual 2D sports game with local multiplayer.

Nombre: Animal Strikers

Desarrollador: Enthariel Games

Periodo: Sep 2023 - Dec 2024

Tecnologías: Unity, C#, Plastic

Sinopsis: In Animal Strikers you test your skills in football using small characters with incredible abilities to win matches like a true legend. Play solo or with friends on the same device.

Género y Etiquetas: Sports, Casual, Local multiplayer.

Sistemas en los que trabajé

Character movement and control system

  • Ground and air movement control
  • Context actions (kick or header)
  • Direct interaction with ball physics
  • AI using same movement rules

Descripción

Arcade football character control system with context-based actions depending on state: kick on ground, header in air. Designed to interact directly with ball physics.

Game loop system

  • Goal and score management
  • Match reset after kickoff
  • Match timer limit
  • Overall match flow control

Descripción

Core loop system managing scoring, resets after goals and match timing, coordinating full match flow.

Abilities system

  • Activatable abilities during match
  • Effects like freeze, size changes, ball speed changes
  • Dynamic gameplay modification

Descripción

Active ability system that modifies gameplay conditions in real time, adding strategy and variability.

Random match events system

  • Random events at end of match
  • Global effects affecting both players
  • Temporary gameplay changes

Descripción

Random post-match events applying global effects that affect both players equally.

Level-based narrative progression system

  • Level unlocks based on goal advantage wins
  • Secret levels via high-margin victories
  • Mini-games between levels
  • Cosmetic unlocks as rewards

Descripción

Progression system unlocking levels based on performance, including secret levels and mini-games.

Character skins and stat system

  • Modular character parts (head, body, feet, tail)
  • Stats modifications (speed, jump, shot power)
  • Cosmetic visual effects

Descripción

Customization system with modular skins affecting gameplay stats and visuals.

Local multiplayer system

  • Up to 2 players on same device
  • Pre-match customization
  • Co-op or competitive local play

Descripción

Local multiplayer system supporting two players with pre-match setup and customization.

Binary save system

  • Binary persistence of game data
  • Optimized save/load performance
  • Player progression storage
  • Designed for platforms like Nintendo Switch

Descripción

Binary save system optimized for performance and platform compatibility.
