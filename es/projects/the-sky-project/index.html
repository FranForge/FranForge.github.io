The Sky Project

The Sky Project

A 2D metroidvania, monster collector and turn-based RPG.

Nombre: The Sky Project

Desarrollador: Enthariel Games

Periodo: Nov 2024 - Sep 2025

Tecnologías: Unity, C#, Plastic SCM

Sinopsis: In a world divided by four planes where mana flows like rivers of power between worlds, a story of love, loss and discovery emerges. A celestial being from a seemingly perfect world embarks on a journey that will challenge everything it knows.

Género y Etiquetas: Monster Collector, Turn-based RPG, 2D platformer, Local multiplayer.

Sistemas en los que trabajé

Creature system

  • Creatures with configurable base stats
  • Level progression with experience and attribute growth
  • Skill learning matrix per level

Descripción

Creature system allowing complex entities with base stats, level growth and experience configuration. Includes an evolution system where each creature defines how attributes grow and which skills are learned at each level.

Advanced combat system

  • Turn-based combat with single and multi-target selection
  • Type system with effectiveness and weaknesses
  • Global energy per turn limiting skill usage
  • Status effects and usable items during combat

Descripción

Turn-based combat with advanced target selection, allowing single or area attacks. Includes type effectiveness system, global energy per turn limiting skill usage, random extra attacks per turn, and item usage with status effects.

Parametrizable combat AI system

  • Enemy behavior configurable via parameters
  • Target priority system (health, level, damage, etc.)
  • Control over skill usage like healing and shields
  • Adaptable AI without modifying base logic

Descripción

Fully configurable enemy AI system allowing behavior definition without changing base logic, including targeting priorities and skill usage rules.

2D platform movement system

  • Horizontal movement with air and ground control
  • Double jump and dash with cooldown
  • Gliding mechanic for fall control

Descripción

Platform movement system with precise control, including jump, double jump, dash and gliding for fluid movement.

Wild creature system

  • Creature spawns based on zones
  • Level range per area
  • Probability-based spawn system

Descripción

Wild creature spawning system defining zone-based encounters with configurable probability and level ranges.

Creature capture and management system

  • Capture wild creatures during combat
  • Rename and customize captured creatures
  • Integration with progression and stats system
  • Player creature management

Descripción

System allowing capture of creatures during combat and adding them to player control with customization and progression integration.

Global state flags system

  • Key-based system for world events
  • Event activation based on progression
  • Story integration

Descripción

Same key-based flag system controlling world events and narrative progression dynamically.

Binary save system

  • Player state persistence in binary format
  • Manual serialization for performance optimization
  • Integrated with debug tools

Descripción

Binary save system for optimized loading and saving, with manual serialization and debug integration.

Debug tools system

  • Real-time game state modification tools
  • Full control over stats, inventory and events
  • Testing without gameplay flow

Descripción

Debug system allowing real-time modification of game state for testing purposes.
